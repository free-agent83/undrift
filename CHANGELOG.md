# Changelog

## 0.1.0

The first release. Undrift checks the files a coding agent writes in a React and Tailwind app against the design
system's own rules: the gate (`undrift gate`, and `--strict` for release), the write-time hook for Claude Code, the
`<Missing>` placeholder for a need the system cannot serve, `undrift init` for an installed design system or a folder
of components, and the later list for problems that were there before.
